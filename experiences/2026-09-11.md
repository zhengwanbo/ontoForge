## DDL 列注解重复导致 ORA-11562 修复

### 背景

用户在执行 DDL 生成后的落库阶段遇到 Oracle 错误：

- `ORA-11562: Duplicate annotation name 'ONTOLOGY_REF' in the ANNOTATIONS clause`

需要定位平台生成的列注解 DDL 为什么会在同一个 `ANNOTATIONS(...)` 子句中重复声明同名 annotation，并修复为 Oracle 可接受的写法。

### 参考现状

本次排查并确认了以下位置：

- `backend/app/services/ddl_service.py`
- `backend/tests/test_ontology_graph_mapping_design.py`
- `experiences/2026-09-10.md`

确认到的根因：

- 当前 `_build_property_annotation_items()` 会为同一个 annotation 名同时输出：
  - `DROP IF EXISTS ONTOLOGY_REF`
  - `ADD ONTOLOGY_REF '...'`
- 这两段被拼进了同一个 `ANNOTATIONS(...)` 子句
- Oracle 会将其识别为同一 annotation 名在同一子句中重复出现，从而报 `ORA-11562`

### 改动文件

- `backend/app/services/ddl_service.py`
- `backend/tests/test_ontology_graph_mapping_design.py`
- `experiences/2026-09-11.md`

### 实施内容

本次将列注解 DDL 生成改为“两段式”：

- 第一步单独输出 drop 语句：
  - `ANNOTATIONS(DROP IF EXISTS ONTOLOGY_UNIT, ... , DROP IF EXISTS ONTOLOGY_REF)`
- 第二步单独输出 add 语句：
  - `ANNOTATIONS(ADD ONTOLOGY_UNIT '...', ... , ADD ONTOLOGY_REF '...')`

具体调整包括：

- 新增 `MANAGED_ONTOLOGY_ANNOTATION_NAMES`
  - 统一声明平台当前托管的 annotation 名集合
- `_generate_column_annotations_ddl()`
  - 不再把同名 annotation 的 `DROP` 和 `ADD` 拼在同一条 SQL
  - 改为按列生成最多两条语句：一条 drop，一条 add
  - 额外输出 `annotation_operation` 便于测试断言和后续排查
- `_build_property_annotation_operations()`
  - 返回 `drop_annotations` 与 `add_annotations`
  - 为后续继续扩 annotation 管理留出清晰接口

这个改法除了修掉 `ORA-11562`，也顺手改善了重复执行 DDL 时的稳定性：

- 先 drop 再 add，可覆盖旧 annotation 值
- 即使某个属性元数据已被清空，也会先清理掉历史残留 annotation

### 验证结果

- `cd backend && python -m compileall app/services/ddl_service.py tests/test_ontology_graph_mapping_design.py`：通过
- `cd backend && python -m unittest tests.test_ontology_graph_mapping_design.OntologyGraphMappingDesignTest.test_generates_table_column_annotations_from_property_metadata tests.test_ontology_graph_mapping_design.OntologyGraphMappingDesignTest.test_generates_view_column_annotations_only_for_projected_columns tests.test_ontology_graph_mapping_design.OntologyGraphMappingDesignTest.test_column_annotation_drop_and_add_are_emitted_in_separate_statements`：通过

补充说明：

- `tests.test_ontology_graph_mapping_design` 整个测试文件存在既有历史失败项，与本次 annotation 修复无关
- 本次只验证了与列注解生成直接相关的 3 个测试用例

### 遗留问题

- 当前未在真实 Oracle 环境再次回放完整 DDL 执行链路，本次验证以生成 SQL 和单测为主
- 若后续增加新的 ontology annotation 名，需要同步扩充 `MANAGED_ONTOLOGY_ANNOTATION_NAMES`

### 下一步建议

1. 在出现该错误的实际 DDL 任务上重新执行一次，确认 Oracle 侧不再报 `ORA-11562`。
2. 后续若继续扩注解能力，可补一组更贴近真实 DDL 任务的服务层集成测试，覆盖重复部署场景。
