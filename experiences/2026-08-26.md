# 2026-08-26

## 平台版本升级至 v1.4.0

### 背景

将平台对外应用版本升级至 v1.4.0，为后续版本发布建立明确标识。

### 改动文件

- `backend/app/core/config.py`

### 实施内容

- 将 FastAPI 应用配置中的 `APP_VERSION` 从 `1.3.0` 更新为 `1.4.0`。

### 验证结果

- `cd backend && python -m py_compile app/core/config.py`：通过。
- `cd backend && python -c "from app.core.config import settings; assert settings.APP_VERSION == '1.4.0'"`：通过。
