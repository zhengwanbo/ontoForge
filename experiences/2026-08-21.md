## 前端 Nginx 部署配置

### 背景

为 Vue/Vite 前端提供可供生产环境引用的 Nginx `server` 配置，并将同源的 `/api/v1` 请求代理到 FastAPI。

### 改动文件

- `ontoforge-front.conf`

### 实施内容

- 配置前端构建目录 `/opt/ontoforge/frontend/dist` 作为站点根目录。
- 使用 `try_files` 将 Vue Router 的前端路由回退到 `index.html`。
- 对带指纹的静态资源启用一年不可变缓存，对入口 HTML 使用 `no-cache`。
- 将 `/api/` 和 `/health` 保持原始路径代理到 `127.0.0.1:8000`，并为 DDL、LLM 等长耗时请求设置 10 分钟代理超时。

### 验证结果

- 本机 Nginx 版本：`1.27.3`。
- `git diff --check`：通过。

### 部署说明

- 部署时需按实际发布目录、域名和 HTTPS 证书调整 `root`、`server_name` 及 TLS 配置。

## 业务规则活动中的指标定义

### 背景

需要在“业务对象构建 > 业务规则活动”中先维护本体对象的业务指标口径，例如有效客户、有效收入和可用库存，再配置基于指标的业务规则和后续活动。

### 改动文件

- `backend/app/models/models.py`
- `backend/app/schemas/schemas.py`
- `backend/app/api/business_rules.py`
- `frontend/src/api/index.ts`
- `frontend/src/views/business/BusinessRulesActivities.vue`

### 实施内容

- 新增 `sys_metric_definition`，按分析域和本体对象保存指标编码、名称、类别、口径说明、计算表达式、聚合方式、统计周期、单位、阈值 JSON 与启用状态。
- 新增指标定义 CRUD API，并校验用户的分析域权限、关联本体对象归属和同域指标编码唯一性。
- “业务规则活动”新增首个“指标定义”页签，支持按当前分析域选择本体对象、新增、编辑和删除指标；业务规则和业务活动页签维持原功能。
- 指标编辑表单提供有效客户、有效收入、可用库存等场景所需的口径、计算表达式和阈值配置输入项。

### 验证结果

- `python -m py_compile backend/app/models/models.py backend/app/schemas/schemas.py backend/app/api/business_rules.py`：通过。
- `frontend/npm run build`：通过。
- `git diff --check`：通过。
